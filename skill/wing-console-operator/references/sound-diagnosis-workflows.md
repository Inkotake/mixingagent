# Sound Diagnosis Workflows

## No-Sound Workflow
1. Scope: who, what, where
2. Resolve target from room patch sheet
3. Read WING state (mute, fader, source, routing)
4. Read meters (input, channel, bus, main)
5. Classify breakpoint
6. Choose next test
7. Only propose fix when evidence is clear

## Feedback Workflow
1. Identify location: which mic/speaker pair?
2. Check monitor send levels
3. Check mic placement
4. Check EQ for resonant frequencies
5. Reduce level or EQ cut before any other change

## Monitor Mix Workflow
1. Identify performer and their bus
2. Read current send levels
3. Adjust in small increments (max 6dB)
4. Confirm with performer
5. Never push above 0dB on sends
